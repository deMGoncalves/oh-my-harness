Para entender o porquê de tudo isso, entenda como a IA funciona.

Um modelo de linguagem não pensa como uma pessoa nem lembra de você. Ele prevê a próxima palavra, uma de cada vez, a partir do que está na janela de contexto. Harness, specs e estrutura de pastas existem por causa disso.

// 01 · Ela prevê

A IA escolhe a próxima palavra mais provável

O texto é quebrado em pedaços chamados tokens. A cada passo, o modelo calcula a probabilidade de cada token possível vir a seguir, escolhe um, e repete — milhares de vezes por resposta.

Não existe uma resposta guardada em algum lugar. Existe a continuação mais provável para aquele contexto. Mude o contexto e muda o que é provável.

Por que isso importa

Com 80% de acerto por token, uma resposta de 1.000 tokens tem chance praticamente nula de sair inteira correta: 0,8 elevado a 1.000 ≈ 0. Cada pedaço de contexto certo aumenta a chance do token certo.

// 02 · Ela só sabe o que está na janela

A janela de contexto é tudo o que ela vê

A janela é o texto que o modelo recebe de uma vez: instruções, arquivos lidos, a conversa. Ela é grande, mas finita — e não é lida por igual. Quanto mais cheia, menos confiável fica a leitura.

// 03 · Ela não lembra

Cada tarefa começa do zero

Uma pessoa paga o custo de entender o sistema uma vez, no onboarding, e acumula por anos. O agente paga a cada tarefa: começa sem memória, lê o que estiver no caminho e esquece ao terminar.

É a diferença entre um investimento e uma assinatura. Uma base que espalha o conhecimento cobra essa assinatura de cada tarefa, para sempre.

// 04 · Ela completa lacunas

Alucinação é uma resposta plausível

Quando falta informação, o modelo não para: ele completa com o que é mais provável em geral. O resultado soa certo, compila, e está errado para o seu caso.

Por isso 66% dos devs recebem respostas “quase certas”. O problema raramente é o modelo — é o que faltou na janela.

Fonte: Stack Overflow Developer Survey 2025

// 05 · Um agente é um loop

Pensar, agir, observar — e repetir

Um agente é o mesmo modelo dentro de um ciclo: ele decide um passo, usa uma ferramenta, lê o resultado e decide o próximo. É poderoso, e cada volta consome a mesma janela finita.

// 06 · Do cálculo à estrutura

Cada passo do cálculo explica uma pasta

Juntando tudo: o modelo repete seis passos a cada token. Cada passo tem um jeito de errar — e cada pasta do ecossistema existe para fechar um deles. Não é preferência de organização; é engenharia em volta do cálculo.

O certo precisa ser o provável

O modelo escolhe o provável. A regra escrita em specs/ e changes/ desloca a probabilidade para o certo — e o verify existe porque, em mil tokens, algum ainda vai errar.

// A pergunta que ninguém faz em voz alta

A IA vai tomar o meu emprego?

Ela troca a tarefa, não o engenheiro. Tudo o que você leu acima aponta para o mesmo lugar: a IA precisa de alguém que decida o quê e por quê, especifique o suficiente para o provável virar o certo, e verifique o que ela entregou.

Quem entende como ela funciona deixa de competir com ela e passa a dirigi-la.

64%

dos desenvolvedores não veem a IA como ameaça ao emprego.

Fonte: Stack Overflow, 2025

75%

ainda procuram uma pessoa quando não confiam na resposta da IA.

Fonte: Stack Overflow, 2025
